Performance

Launch flags follow this machine: compact on a CPU-only host under 16 GB RAM, full when a GPU is present or RAM is 16 GB or more. Set VOCAGATEWAY_CLEANUP_PROFILE=compact or full to force one. The cleanup documentation lists the same flags for a server you run yourself.
